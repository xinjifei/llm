# 项目目的

本项目旨在通过亲手搭建并训练一个最小语言模型，理解人工智能与大语言模型的底层算法，以及模型如何从数据中学习并生成文本。

项目使用 Python，允许使用 NumPy，不使用 PyTorch 等现成的深度学习框架，也不依赖预训练模型权重。目标是从随机初始化的参数出发，用少量文本训练一个字符级小型 Transformer，完成从模型搭建、训练到文本生成的完整闭环。

项目以学习和理解为核心，不追求大规模参数、实用聊天能力或商业模型的效果。成功的标准是能够解释自己搭建的模型如何运作、为什么能够学习，并通过实际运行验证理解。

学习以项目中的具体问题为出发点，在解决问题的过程中建立对相关概念与算法的认识。
